# myChildrenPaperToy

아이와 종이로 만드는 놀이 세트. 인쇄해서 오리고, 접어서 입힌다.

**주소** → https://themoka7.github.io/myChildrenPaperToy/

## 지금 들어 있는 것

### 공주 옷입히기 — A4 6장

종이인형 한 명에게 머리·드레스·신발·장신구를 갈아입히는 세트.
공주는 1명이고, 1번 시트에 같은 공주가 4장 인쇄된다 — 네 벌을 동시에 입혀 세워 두고 놀 수 있게.

| 시트 | 내용 |
|---|---|
| 1. 공주 | 본체 4명 + 세우는 받침 4개 |
| 2. 드레스 | 6벌 |
| 3. 머리 | 6가지 |
| 4. 왕관 · 귀걸이 · 목걸이 | 왕관·머리띠 5, 귀걸이 6쌍, 목걸이 4 |
| 5. 신발 · 가방 · 소품 | 신발 6켤레, 가방 4, 손소품 4 |
| 6. 망토 | 망토 3벌 + 입혀 본 예시 |

갈아입힐 수 있는 조합은 **25,920가지**.

## 인쇄

시트를 열고 **인쇄** → 배율 **100%** → **배경 그래픽 켜기**.
두꺼운 종이(160g 이상)에 뽑으면 훨씬 잘 선다. 얇은 종이면 인쇄한 뒤 두꺼운 종이에 붙여서 오린다.

위쪽 **색칠판**을 켜면 색이 빠진 선그림으로 나와서 아이가 직접 색칠할 수 있다.

## 선 읽는 법

- **회색 점선** — 가위로 오리는 선
- **머리 얼굴 창의 얇은 점선** — 여백 없이 이 선을 그대로 오린다 (어른이 오려 주세요)
- **파란 짧은 점선** — 뒤로 접는 선 (오리지 않는다)
- **굵은 검은 선** — 칼집 (받침 가운데. 한 번만 자른다)

## 입히는 순서

```
공주 → 머리 → 드레스 → 망토 → 신발 → 목걸이 → 귀걸이 → 왕관 → 손소품
```

받침 가운데 굵은 선에 칼집만 넣고, 공주 발밑 꽂이를 끼우면 혼자 선다.

## 고치거나 늘리기

시트는 전부 생성물이다. 직접 고치지 말고 다시 빌드한다.

```bash
python3 tools/build_paperdoll.py           # 시트 6장 + index.html 다시 생성 (검사 포함)
python3 tools/check_paperdoll.py           # 검사만
python3 tools/render.py sheets/sheet2.html # 실제 인쇄 엔진(Chromium)으로 그려 확인
```

검사기는 눈으로 못 잡는 것을 본다 — 인쇄하면 A4 1장인지, 오림선이 종이 밖으로 나가거나
서로 붙지 않는지, **탭이 옷 폭에 묻히지 않았는지**, 드레스 밑단 아래로 신발이 보이는지.

치수·부착 방식·설계 근거는 **[DESIGN.md](DESIGN.md)** 에 있다.
새 파츠를 추가하거나 다른 세트를 만들려면 그것부터 읽으면 된다.

렌더링에는 Chromium 이 필요하다 (`pip install playwright`).
없으면 `--no-check` 로 빌드만 할 수 있다.

## 배포

`main` 또는 `claude/**` 브랜치에 푸시하면 GitHub Actions 가 저장소를 그대로 Pages 에 올린다.

**Pages 는 저장소 설정에서 한 번 켜 줘야 한다** — Settings → Pages → Build and deployment →
Source 를 `GitHub Actions` 로. 워크플로에 `configure-pages` 의 `enablement: true` 가 들어 있지만,
워크플로 토큰으로는 Pages 를 처음 켤 권한이 없어 `Resource not accessible by integration` 으로
실패한다. 한 번 켜 두면 그 뒤 배포는 전부 자동이다.
